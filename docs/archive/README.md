# Archive: retired specs

Spec-driven development was retired on 28 October 2026
([ADR 0013](../adr/0013-retire-spec-driven-development.md)). The documents here are kept unchanged
as a historical record: test titles such as `SE-07.14 …` and the Step 2 evidence refer to the
criterion IDs they define. Nothing new is written here, and their statuses, approvals and gates no
longer apply. Links inside them to the constitution or the spec workflow point to files that no
longer exist.

- [`step-specs/`](step-specs/README.md): step specs (Step 2 holds its 74 criteria; Step 3 was a
  draft charter never approved)
- [`specs/`](specs/): feature specs 001 to 008, each with `spec.md`, `plan.md` and, where written,
  `tasks.md`
